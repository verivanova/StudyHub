# StudyHub
**StudyHub** — веб-платформа для размещения, просмотра и оценки учебных материалов. Проект помогает собирать полезные образовательные материалы в одном месте и упрощает доступ к ним.

##  Демонстрация проекта

StudyHub размещён на хостинге и доступен в интернете. С сайтом можно ознакомиться без локальной установки.

**Ссылка на сайт:** https://studyhubik.great-site.net

Проект опубликован в открытом доступе, поэтому каждый желающий может посетить сайт и ознакомиться с его возможностями.


## Возможности

- Просмотр списка учебных материалов.
- Просмотр подробной информации о каждом материале.
- Разделение материалов по категориям.
- Добавление и редактирование материалов в режиме администратора.
- Добавление описания, содержания, особенностей и уровня сложности материала.
- Загрузка обложек и учебных файлов.
- Добавление ссылок на внешние учебные ресурсы.
- Оценка материалов по пятизвёздочной шкале.
- Отображение среднего рейтинга и количества оценок.
- Адаптивный интерфейс для компьютеров и мобильных устройств.

## Используемые технологии

- **HTML5** — структура страниц.

- **PHP** — серверная логика.

## Запуск проекта локально

### 1. Требования

Для локального запуска необходимы:

- Apache;
- PHP;
- MySQL;
- браузер.

### 2. Размещение проекта

Скопируйте проект в папку, доступную веб-серверу Apache.

Например, в используемом локальном окружении проект находится в папке:

```text
C:\Users\user\Desktop\StudyHub
```

### 3. Создание базы данных

Создайте базу данных MySQL с названием:

```sql
CREATE DATABASE studyhub;
```

После этого импортируйте SQL-структуру проекта, если она предоставлена отдельно.

В базе данных используются таблицы для хранения учебных материалов, категорий и оценок.

### 4. Настройка подключения к базе данных

Откройте файл:

```text
php/db.php
```

Укажите параметры подключения к MySQL:

- адрес сервера;
- название базы данных;
- имя пользователя;
- пароль.

Не публикуйте реальные пароли и другие секретные данные в открытом репозитории.

### 5. Запуск

Запустите Apache и MySQL, затем откройте сайт в браузере:

```text
http://localhost/html/index.php
```

Страница с учебными материалами:

```text
http://localhost/html/materials.php
```
## Основные разделы сайта

### Главная страница
Содержит основную информацию о платформе и помогает пользователям перейти к учебным материалам.

### Каталог материалов
Позволяет просматривать доступные учебные материалы, знакомиться с их описаниями и выбирать подходящие темы.

### Страница материала
Содержит подробную информацию об учебном материале: описание, содержание, уровень сложности, полезные советы, вложения и пользовательские оценки.

### Панель администратора
Предназначена для управления учебными материалами. Администратор может создавать, редактировать и удалять записи.

## Управление содержимым
Для каждого учебного материала предусмотрены следующие данные:

- Название и описание.
- Основное содержание.
- Категория.
- Особенности материала.
- Уровень сложности.
- Полезный совет.
- Обложка.
- Учебный файл или внешняя ссылка.

## Рейтинг материалов
Пользователи могут оценивать учебные материалы по шкале от 1 до 5 звёзд.

На странице материала отображаются:
- средняя оценка;
- количество оценок;
- возможность оставить оценку.

Для хранения оценок используется таблица `material_ratings`.

Ограничение повторного голосования реализовано на основе PHP-сессии.

## Адаптивность
Интерфейс StudyHub разработан с учётом использования на разных устройствах. Сайт поддерживает просмотр с компьютеров, планшетов и смартфонов.


## Размещение на хостинге

Проект может быть размещён на PHP-хостинге с поддержкой MySQL.

Для публикации необходимо:

1. Загрузить файлы проекта на хостинг.
2. Создать базу данных MySQL.
3. Импортировать структуру базы данных.
4. Настроить подключение в `php/db.php`.
5. Проверить права на запись в папку `uploads/`.
6. Проверить работу страниц и загрузку файлов.

## Безопасность

- Данные форм проверяются на стороне сервера.
- Для отправки оценок используется CSRF-токен.
- Загружаемые файлы проходят проверку типа и расширения.
- Секретные данные подключения к БД не следует хранить в публичном репозитории.

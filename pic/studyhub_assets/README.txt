StudyHub — отдельные вырезанные ассеты

Файлы вырезаны из общего листа автоматически. Это обычные изображения с фоном листа (не все имеют прозрачность), поэтому при необходимости можно использовать их как декоративные элементы.

Как использовать:
1. Распакуйте архив.
2. Скопируйте нужные PNG в папку images/ вашего проекта.
3. В HTML вставляйте, например:
   <img src="images/hero-study-illustration.png" alt="Учебные материалы">
4. Для маленьких интерфейсных иконок лучше использовать Lucide Icons, чтобы они были чёткими и легко меняли цвет.

Важно: некоторые вырезки могут включать немного пустого пространства по краям, потому что они взяты с общего листа.
